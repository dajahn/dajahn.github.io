# CV Website

A simple personal CV website, built with plain HTML, CSS, and JavaScript.

## Features

- Bilingual content in German and English
- Responsive CV layout
- Project, experience, education, and skills sections
- Language and theme toggles
- Print-friendly view


## Files

- `index.html` — page structure
- `styles.css` — site styling
- `script.js` — bilingual content and interactive behavior
